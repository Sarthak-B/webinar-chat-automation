A / Team password

Everything else below is shared for the whole team and loads by itself on every phone and laptop. No GitHub token or sheet ID is needed.

B / Shared team settings (read-only)

These come from dashboard/config.json on GitHub, so every device always uses the same links. To change one, update that file. Every device picks it up the next time it opens.

C / Admin only

Apps Script setup: open the chat sheet → Extensions → Apps Script, paste the code below and set KEY (the team password). In Project Settings → Script properties, add GITHUB_TOKEN. To update it later, always use Deploy → Manage deployments → ✏️ → New version. That keeps the same link. A New deployment creates a new link, which then has to go into config.json.
